# Roamly — Travel & tourism website

A responsive, single-page travel discovery website. It runs directly in a modern browser without a build step or dependencies.

## Open locally

Open `index.html` in a browser, or serve this folder with any static web server.

## Included interactions

- Search trips by destination, country, travel style, or description.
- Filter trips by coast, culture, or nature.
- Save trips; saved choices persist in the browser using local storage.
- Open a trip request form, enter traveler details, and receive an on-page confirmation.
- Submit the newsletter form for an on-page success state.
- Use Ctrl+K / Cmd+K to jump to destination search.

Trip requests and newsletter signup are front-end demonstrations. Connecting a real booking or email service requires a backend/provider. Destination photography and fonts load from Unsplash and Google Fonts when online.
